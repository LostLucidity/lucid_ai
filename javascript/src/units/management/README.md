# Unit Management Module

This directory provides functions to handle unit training, commands, and general management. It controls the lifecycle and roles of units, including building, training, and task assignment.

### Files:
- **basicUnitUtils.js**: Core utilities for handling unit properties and actions.
- **builderUtils.js**: Utilities specific to builder units and their tasks.
- **training.js** and **trainingCommands.js**: Manage training commands and training-related logic.
- **unitCommands.js**: Executes commands for unit actions.
- **unitHelpers.js**: Helper functions for unit-related calculations.
- **unitOrders.js**: Organizes and issues orders to units.
- **unitTrainingUtils.js**: Specific utilities for handling unit training.

### Purpose:
The `unit management` module organizes all unit-related actions, ensuring efficient task distribution and optimizing the bot's unit operations.
