# Economy Module

This directory manages all aspects of economic strategy, from resource gathering to worker assignment. It is essential for maintaining a strong economy and resource flow in the game.

### Files:
- **economicManager.js**: Centralized management for economic strategy and decision-making.
- **economyManagement.js**: Core functions for economic activities.
- **gatheringManagement.js**: Manages resource gathering logic.
- **trainingManagement.js**: Handles training assignments for workers and military units.
- **workerAssignment.js**: Manages the allocation and reassignment of workers.
- **workerService.js**: Provides services related to worker management and task distribution.

### Purpose:
The `economy` module is focused on resource management and is a key factor in game progression and sustainability.
