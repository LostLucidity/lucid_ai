# Actions Module

This directory contains utilities and strategies for handling unit actions in the game. It centralizes logic around unit movement, selection, and action strategies.

### Files:
- **actionCollector.js**: Collects actions based on unit priorities and contexts.
- **actionStrategy.js**: Defines strategies for selecting and executing actions.
- **unitActionUtils.js**: Utility functions to assist with unit action handling.
- **unitSelection.js**: Manages unit selection logic based on game strategy.

### Purpose:
The `actions` module is essential for controlling unit behavior and decision-making in the bot.
